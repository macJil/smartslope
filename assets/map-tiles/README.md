# Irisan local map tiles

This repository includes 110 local image tiles in directories `12`, `13`,
`14`, and `15`. Preserve their `zoom/x/y.png` structure, such as
`assets/map-tiles/15/27356/14867.png`.
The SmartSlope map uses `maxNativeZoom: 15` to enlarge these existing tiles
at higher zoom levels. No zoom 16–18 files are needed.

Confirm the images' original source and redistribution terms before
public deployment. Map data attribution is shown in the map.
